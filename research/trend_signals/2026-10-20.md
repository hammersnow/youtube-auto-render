# Trend signal — 2026-10-20

## Candidate: `chain_reaction_choice`

A short physics/causality puzzle: show a compact Rube-Goldberg-like machine already in a visually loaded state and ask **“Which trigger finishes the chain?”** (A/B/C). The viewer commits before motion starts; one trigger launches a 2–4-stage continuous chain reaction, while the others fail in visually understandable ways. End on the completed mechanism in a composition that can cut/loop back to the opening state.

This is not a copy of any specific video. It extracts the recurring mechanics of prediction + continuous satisfying motion + causal payoff.

## Why it adds something to V7

`predict_path` asks where one moving object will end. `chain_reaction_choice` asks which initial cause will successfully propagate through several dependent stages. That gives us a different cognitive task: **causal reasoning**, not trajectory tracking. It also differs from `physics_error`: the machine can obey normal physics; the challenge is predicting propagation.

Potential stages: marble → lever → domino/gate → second marble → target. Keep the whole mechanism visible so the viewer can reason from frame 0.

## Suggested structure

1. **0–1 s:** full machine visible; “WHICH TRIGGER WORKS? A B C”. No intro/logo.
2. **1–4 s:** short commitment window with subtle pulse on A/B/C; machine remains readable.
3. **4–10 s:** selected/actual trigger fires; continuous chain reaction with collision/impact SFX.
4. **10–12 s:** target lights/snaps into place; brief answer marker.
5. **12–13 s:** composition returns/cuts cleanly toward the opening state for replay.

Do not artificially extend runtime just to chase generic benchmark claims; first test a compact 10–15 s version against the channel’s own retention/replay data.

## Free implementation

Python + NumPy for deterministic kinematics/state machine; OpenCV/Pillow for drawing; FFmpeg for encode/audio. No external media or paid model/API needed. Use simple circles, rails, gates, pivots and domino rectangles; precompute static geometry and animate only moving bodies/impact particles.

## Expected benefit

- immediate question hook;
- prediction creates commitment before payoff;
- multi-stage motion supplies natural pattern interrupts without hard cuts;
- satisfying causal completion can encourage replay;
- procedural layout can generate many original variants without reused footage.
