## Proposed original family: `spill_limit`
Hook in frame 1: **`WHICH MOVE SPILLS IT?`** or **`STOP BEFORE IT SPILLS`**.

Use an abstract procedural vessel / particle-liquid scene rather than reproducing any creator's prop. Show 2–3 candidate actions or one continuously changing control:
- rotate a vessel toward a marked safe angle;
- drop glowing particles into an irregular container toward a fill line;
- open one of A/B/C valves/gates and predict which route overflows;
- remove one support/pin and predict whether the contained particles remain below the rim.

The answer must be deterministic. During reveal, freeze near the threshold, draw the computed spill boundary / fill line, then run a short transparent or slow-motion pass/fail replay. The payoff should be a clean near-miss or a clearly visible first escaping particle, not arbitrary decoration.

## Difference from current V7
Current production proven families are `wrong_motion`, `animated_maze`, `memory_shuffle`, `spot_difference`; experiments are `physics_error`, `portal_path`, `laser_core`, `flow_field`.

`spill_limit` is not anomaly spotting (`physics_error`), path prediction/tracing, memory, maze solving, or occlusion counting. Its core task is **threshold prediction under a conservation/containment constraint**: the viewer estimates when a physical state crosses a visible failure boundary.

It also differs from research candidate `perfect_fit`: that asks geometric compatibility at a final pose, while `spill_limit` asks whether a dynamic quantity/state remains inside a constraint during motion.

## Free implementation path
Python + NumPy + OpenCV/Pillow + FFmpeg only.

Avoid expensive fluid simulation. Use deterministic 2D particles with gravity/collision against simple polygon walls, or a clipped polygon/height-field approximation for liquid. Compute overflow from particles crossing the rim or from polygon intersection. Render glow/trails and a high-contrast fill/rim line using the existing V7 visual engine. No external footage, paid model, paid API, or proprietary asset is required.

## Expected benefit
- First-frame comprehension: container + rim/fill line makes the failure condition obvious.
- Continuous tension: state approaches a visible threshold instead of waiting on a static timer.
- Satisfying reveal: near-miss / first-spill moment gives a precise visual payoff.
- Replay utility: viewers can rewatch the exact threshold crossing.
- Large procedural state space from vessel geometry, particle count, gravity, valve/support layout and threshold.
