Private creator automation

YouTube Auto Publisher

This is a single-user automation project that renders original visual-puzzle Shorts, analyses the owner's channel performance, and schedules new videos on the owner's YouTube channel.

How Google data is used

  • YouTube upload access is used only to upload and schedule videos created by this project.
  • YouTube read access is used to detect duplicate uploads and confirm publishing results.
  • YouTube Analytics access is used to improve publishing times and content decisions.

The application is not offered as a public service and does not sell or share Google user data.
