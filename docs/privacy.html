Privacy Policy

Effective date: 29 September 2026

YouTube Auto Publisher is a private, single-user automation project operated by the owner of the connected YouTube channel.

Data accessed

The application requests permission to upload videos, read YouTube channel and video information, and read YouTube Analytics reports. It accesses only the Google account explicitly authorised by the owner.

Purpose of use

Google user data is used solely to upload and schedule original Shorts, prevent duplicate publishing, verify publishing results, and evaluate aggregate channel performance to improve future content and timing.

Storage and security

OAuth credentials are stored as encrypted GitHub Actions secrets. Workflow logs do not intentionally print access or refresh tokens. Limited publishing metadata and non-secret content hashes may be retained to prevent duplicate uploads.

Sharing and transfer

Google user data is not sold, rented, transferred, or disclosed to third parties. It is processed only by Google APIs and GitHub Actions as necessary to run the owner's private automation.

Retention and deletion

Publishing metadata is retained only while needed to operate and protect the automation. The owner can revoke the application's Google access at any time from Google Account security settings and can delete stored workflow artifacts and repository data.

Contact

Questions about this policy can be directed to the project owner through the hammersnow GitHub profile.
