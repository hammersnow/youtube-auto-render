# V7 Creative R&D — 2026-10-19

## Candidate: refractive liquid-glass puzzle layer

Use a moving convex glass lens as part of the puzzle mechanic: a path/symbol is visibly displaced only through the lens. This remains an isolated R&D candidate; it is not wired into production and `glass_reveal` is not in the active family pool.

### Revised implementation

`scripts/rd_v7_liquid_glass_preview.py` now renders a high-frequency puzzle background (grid, labelled symbols and a path) so refraction is visually obvious. The lens moves on a smooth closed path and produces both:

- `outputs/rd-v7-liquid-glass/preview.png`
- `outputs/rd-v7-liquid-glass/preview.mp4` — 2.5 s, 24 FPS, 540x960

The displacement field, feather mask, rim and highlight are precomputed once. Per frame, `cv2.remap` runs only on the fixed lens ROI (311x411), not the 540x960 frame. No new dependency, paid API/model or external media is used.

### Smoke test

```bash
python3 scripts/rd_v7_liquid_glass_preview.py
```

The script asserts PNG/MP4 existence and size, MP4 decode success, dimensions, exact 60-frame count and first-frame shape. It prints total render time and milliseconds/frame.

Local validation of the ROI render loop in the review environment measured about **0.43 s / 60 frames (~7.2 ms/frame)** before MP4 encoding. Treat this as a directional benchmark only; GitHub-hosted runner timing can differ.
