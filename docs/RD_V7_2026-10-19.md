# V7 Creative R&D — 2026-10-19

## Candidate: refractive liquid-glass puzzle layer

2026 motion-design research repeatedly highlights liquid/glossy glass, vivid gradients, expressive kinetic type and tactile texture. V7 already has mesh gradients, bloom, grain, glass panels and motion trails, so the highest-value incremental experiment is **actual refractive glass** rather than another decorative overlay.

### Proposed use

Use a moving convex glass lens as part of the puzzle mechanic, not merely decoration: an object/path/symbol is only correctly visible through the lens. This can become an experimental family (`glass_reveal`) or a reveal treatment for `spot_difference` / `portal_path`.

### Implementation

`scripts/rd_v7_liquid_glass_preview.py` implements CPU-only refraction using NumPy displacement fields + `cv2.remap`, with soft frosted blending, specular rim and highlight. No new package, model, API, asset or paid service is required. It is isolated from production and writes only `outputs/rd-v7-liquid-glass/preview.png`.

### Smoke test

```bash
python3 scripts/rd_v7_liquid_glass_preview.py
python3 - <<'PY'

p='outputs/rd-v7-liquid-glass/preview.png'
```
